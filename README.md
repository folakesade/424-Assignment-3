## Project Overview
This project visualizes customer activity across Afro Joe's Coffee & Tea, Cafe 53, and Philz Coffee using static and interactive heatmaps.

## Files
- `static_heatmap.py` - Static heatmap code
- `static_heatmap.png` - Static heatmap
- `interactive_heatmap.py` - Interactive heatmap code
- `interactive_heatmap.html` - Interactive heatmap
- `report.md` - Assignment report
- `data/` - Dataset and evaluation data

## How to Run
Install dependencies:

```bash
python3 -m pip install pandas matplotlib numpy
```

Run the static heatmap:

```bash
python3 static_heatmap.py
```

Open `interactive_heatmap.html` in a browser to view the interactive heatmap.
